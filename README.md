# YouTube Clone 🎬

A YouTube-inspired video browsing application built with React and Vite. This project recreates a simple video platform interface with search functionality, video thumbnails, and a sidebar navigation menu.

## ✨ Features

- 🔍 Search for videos using keywords
- 🎥 Display video thumbnails, titles, and channel names
- 📱 Responsive video grid layout
- 🧭 Sidebar navigation with Home, Trending, Subscriptions, and Library
- ▶️ Open videos on YouTube
- 🌙 Dark-themed user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- YouTube Data API v3

## ⚙️ Setup

1. Clone this repository.
2. Install the dependencies using `npm install`.
3. Configure your own YouTube Data API v3 key.
4. Start the development server using `npm run dev`.
5. Open the local URL provided by Vite in your browser.

## 🔐 API Configuration

This project uses the YouTube Data API v3 to retrieve video information.

- Create and configure your own API key through Google Cloud Console.
- Enable the YouTube Data API v3.
- Do not commit private credentials or unrestricted API keys to a public repository.
